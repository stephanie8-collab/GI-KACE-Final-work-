MY REPORT ON THE PRODUCT-DETAILS .JS FILE 
The product-details.js file was made to help an online shop show the right product 
information on its product page. The code looks at the product ID in the web address and 
uses it to find the correct product. If the product exists, the page shows its name, price, 
description, and picture. If the product does not exist, the page sends the customer back 
to the “All Products” page, so they don’t get stuck. 
The script also changes the gallery's images, so they match the product and add text for 
accessibility. Another part of the code makes the “Add to Bag” button work. When a 
customer clicks it, the product is added to the shopping cart and a message pop up to 
confirm it. 
Furthermore, this code connects the product data to the website page. It makes sure 
customers always see the right product and can easily add it to their cart. The reason for 
writing this code was to make shopping easier, and more enjoyable for customers.
